# TaskNest Frontend

This is the frontend for TaskNest, a productivity and project management application built with Next.js.

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

## Project Notes

- App Router with Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui components
- Dashboard and task management screens

## Useful Commands

```bash
npm run build
npm run start
npm run lint
```
